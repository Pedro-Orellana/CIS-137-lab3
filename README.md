# CIS-137-lab3 - Memory Game App

This is a fairly simple, but highly interactive app that demonstrates my proficiency in understanding and applying iOS development concepts.

The app is a card memory game, where the player flips a card, and then tries to find a matching card for it. If they don't find the match, the cards flip back again, making the player remember where the cards were for the next time they flip another card.

Within the app, I applied mobile development concepts, like the MVVM architecture for the main structure and logic of the app, animations and transitions for moving views, and SwiftUI structures and paradigms to create those views.
